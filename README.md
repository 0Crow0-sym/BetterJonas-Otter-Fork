# Better Jonas Devices - Otter Fork

A community patch and development fork of the **Better Jonas Devices** mod for the survival game **Vintage Story** (Targeting Game Version `1.22.1+`).

This mod introduces custom mechanics, adjustments, and vital code fixes to make rare, technological Jonas lore items significantly more useful, practical, and rewarding during survival gameplay.

## ✨ Key Features
* **Return Teleporter Logic Fixes:** Restructured state handling for the discharged and deployed forms of the base return teleporters.
* **Custom Graphics Shaders:** Optimized visual rendering rules for environmental elements including custom cloud dynamics, clear night sky transitions, and stabilized night vision overlay behavior.
* **Localization Files:** Fully integrated translation profiles providing native support for both English (`en`) and Ukrainian (`uk`) languages.

## 🛠️ Technical Profile
* **Mod ID:** `betterjonasdevicesfixedagainotterfork`
* **Version:** `2.1.6`
* **Environment Side:** Universal (The exact same mod bundle is required on both the client and host server)
* **Target Runtime:** Built utilizing `.NET 10.0` core structures.

## 🚀 Installation Guide
1. Navigate to the **Releases** tab on the right side of this GitHub repository page.
2. Download the pre-packaged `betterjonasdevicesfixedagain_otterfork_2.1.6.zip` file.
3. Move the downloaded `.zip` file directly into your local Vintage Story `Mods` directory without extracting it.
4. Verify that your game client version aligns with the server mod configurations before attempting connection.
